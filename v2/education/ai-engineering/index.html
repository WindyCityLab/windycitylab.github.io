AI Engineering

AI Engineering is a project-first course about building dependable software with models, agents, data, and real interfaces—not simply learning how to chat with an AI.

The 2026 curriculum moves from command-line and data foundations into LLMs, context, APIs, databases, agents, deployment, and a shared Habitat system operating in the live Kepler world.

The shared world, explained

Kepler is a simulated planetary environment. Habitat is the software students build to manage resources, crew, and construction in that world. It gives their code a shared setting where teams can see whether their systems work together.

Course outline

One layer builds on the next.

01

Computer science and digital foundations

A systems-level introduction to computing, AI, and the path from physical signals and stored data to software that can reason over language.

02

Developer setup, terminals, and command-line tools

Installing the working toolchain, navigating the terminal, understanding command structure, and learning to discover an unfamiliar CLI rather than treating it as a black box.

03

Markdown, JSON, TypeScript/Bun, Git, and GitHub

Representing documents and structured data, building typed command-line software, managing repositories, and using version control as part of everyday engineering work.

04

LLM fundamentals: models, tokens, and chat training

Base models, tokenization, chat training, model behavior, and the technical distinctions behind systems that can generate and respond to language.

05

Prompt engineering, context engineering, and agent skills

Designing prompts, AGENTS.md files, reusable skills, and working context so coding agents can operate reliably within a real project.

06

Software design, object-oriented programming, and CLI development

Turning requirements into objects, commands, and discoverable interfaces while building the Habitat CLI for both human and agent users.

07

Machine learning, reinforcement learning, embeddings, and semantic search

Connecting learning concepts to practical systems through reinforcement learning, text embeddings, databases, and search based on meaning rather than exact keywords.

08

APIs, HTTP, REST, DNS, authentication, and cryptographic keys

Working across network boundaries with requests, RESTful interfaces, API tokens, environment files, DNS, asymmetric keys, and secure service access.

09

Servers, deployment, systemd, OpenClaw, MCP, and WebSockets

Deploying software to a real server, keeping it running, connecting agent infrastructure, and adding live event communication between services and interfaces.

10

Kepler/Habitat capstone development

Teams integrate blueprints, construction, crew, exploration, collection, alerts, dashboards, live Kepler ticks, and agent capabilities into one working system and final presentation.
